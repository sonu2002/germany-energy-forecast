How it works

Setting. At midnight after day D, all 24 hours of day D+1 are predicted. Features only use information known at that moment: the same hour 1, 2, 7 and 14 days earlier, yesterday's mean, min and max, last week's mean, calendar features and German public holidays (incl. Easter-based ones, computed from scratch). A unit test checks that nothing from the forecast day leaks into the features.

Model. scikit-learn HistGradientBoostingRegressor trained on hourly data since 2023. It is compared against two honest baselines: the same hour yesterday, and the same hour last week.

Uncertainty. The 80% band uses split-conformal calibration: hour-specific quantiles of out-of-sample errors. In the backtest the true value fell inside the band in … of hours (target: 80%).

Automation. A scheduled GitHub Actions workflow downloads new SMARD data, runs the tests, re-runs the backtest, writes docs/data/dashboard.json and commits it. This page is static and reads that file.
